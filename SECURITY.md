# Security policy

## Supported versions

hofund is pre-alpha. No release is supported yet. Security fixes apply to the
`main` branch.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub Security Advisories:

<https://github.com/logibricks-io/open-heimdall-hofund/security/advisories/new>

Do not open a public issue for a security report.

Include what you found, the commit you tested, and how to reproduce it. The
maintainers will acknowledge the report and coordinate a fix. Please write the
report in English.
