# Feature parity: magpie and hofund

This document compares every user-facing capability of
[yetone/magpie](https://github.com/yetone/magpie), the Go original, with
hofund, the Rust rewrite. Each row cites a source path in each repository.

- **v0.2.0 freeze:** magpie tag `v0.1.3005` (`6abacd46`). That is the reference
  this release is scored against. Many row citations still point at the earlier
  coverage baseline `cbbf316` (v0.1.1504), and a later note recorded `1e15a7a`
  (v0.1.2360); those are historical. Features that landed in the reference
  after `v0.1.3005` are out of this freeze unless the must-list called them out.
- **hofund snapshot:** `main` at `74dbebbc` (R-34: session resume argv and
  Pi-to-omp carry, #798), recounted on 2026-11-13. A row is scored from the
  code that is on this `main`, not from unmerged pull requests. Older line
  citations may still name earlier commits; they are kept as provenance, not
  as a claim that those commits are current. Library writes (row 6) and true
  session recording / MCP execution (design 4.2–4.4) are not on `main`.
  Real-account smoke (`#304`) stays outstanding.
- **Goal:** rebuild every core magpie capability in Rust and do each one better.
  Copy designs that are good, stable, and efficient. Redesign the parts that are unsound.
  `docs/magpie-comparison.md` records each adopt-or-redesign verdict.
  `docs/roadmap.md` is the execution order. A `Stage` column marks each row `core` (stage 1) or `auxiliary` (stage 2).

### Where hofund is already better

1. **Auth on loopback too.** The gateway token is required on loopback as well
   (`crates/kernel/gateway/src/lib.rs`, `authorized`), and tokens are compared in constant time.
   magpie accepts any key on loopback (`ref.md:1920`, "any value works").
   That leaves it open to DNS rebinding and to any local process.
2. **Hub-and-spoke IR.** Each protocol has one codec to and from a shared IR
   (`crates/kernel/ir`, `crates/kernel/codec`). That is N codecs where pairwise translation needs N×N.
   magpie translates in many protocol-specific files under `internal/gateway`
   (`chat.go`, `responses.go`, `anthropic.go`, `gemini.go` and over 190 others).
3. **Quirks are data.** Vendor workarounds are declarative rules in `crates/kernel/quirks`.
   magpie scatters them through per-vendor files (`deepseek_schema.go`, `kimi_schema.go`,
   `grok_schema.go`, `zhipu_envelope.go`).
4. **No vendor names in core code.** A test bans vendor names in every kernel crate that
   no longer holds vendor code, starting with the gateway and router, and dependencies
   flow one way between crates (`docs/architecture.md`).
5. **Secrets out of plain files.** API keys can be `env:NAME` references
   (`crates/kernel/secrets/src/lib.rs`). magpie keeps keys in `providers.json` (`ref.md:2998`, "Files").
6. **Backpressure.** Streams are pulled through the codec, not buffered (`crates/kernel/provider/src/stream.rs`).
7. **Agent backup markers.** Backups use their own markers (`*.hofund.bak`, `*.hofund.absent`, `*.hofund.wrote`)
   and live beside the file (`crates/kernel/agent/src/catalog.rs:479`). A clean disconnect writes the pre-connect bytes back.
   A later edit stays. The backup is removed only after that write is read back and matches.
   `--force` restores the backup bytes.
8. **One config file.** A single TOML file (`crates/kernel/config/src/lib.rs`) replaces about 20
   JSON and YAML state files (`ref.md:2998`). It can be reviewed, diffed and checked
   (`hofund config check`).
9. **Release pipeline.** cargo-dist builds 5 targets plus a universal2 macOS binary,
   with checksums and optional signing (`dist-workspace.toml`, `.github/workflows/release*.yml`).
   Pull requests run `dist plan` and install the pinned Tauri CLI
   (`.github/workflows/ci.yml`). That is reproducible from CI.
10. **Per-upstream model names and reasoning effort.** Each route member names
    the model it sends (`crates/kernel/config/src/lib.rs:98`). Effort is one enum on
    the request (`crates/kernel/ir/src/effort.rs:16`), mapped by each codec. Token
    counts ask a Messages upstream and otherwise return an estimate
    (`crates/kernel/gateway/src/lib.rs:319`).
11. **Connection-nominated headers.** hofund strips every header a response
    nominates in `Connection` (RFC 9110), including `Retry-After`
    (`crates/kernel/plugin-host/src/pool.rs:276-301`). The reference strips only a fixed
    hop-by-hop list and forwards nominated headers
    (`reference: internal/gateway/codex_backend.go:1571-1577`). This is an intentional standards fix.
