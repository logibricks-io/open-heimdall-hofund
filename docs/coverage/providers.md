## Cross-cutting provider gaps in hofund

The list and probe behavior that closes the two gaps below is planned in [models.md](../plugins/models.md). This inventory stays partial until that code lands.

- No scheduled upstream model listing (magpie: `/models` per protocol, models.dev catalog via the `catalog` field, `noList` presets use static lists; `internal/provider/models.go`, `autolist.go`). Azure is the exception: the `azure` plugin reads the deployment list, then `/openai/v1/models`, verified with mocks only. The gateway does not call it on a schedule (feature-parity row 2.9).
- No connectivity test / probe (magpie: `internal/provider/test.go`, `translated_probe.go`, `test_as.go`).
- No auth-header learning (magpie retries with one header when both are refused: `RetryOneAuth`, `authheader.go`).
- No balance readers (DeepSeek, Kimi, OpenRouter, SiliconFlow, StepFun, Command Code, Ollama Cloud, AiHubMix; `internal/provider/balance.go`) and no plan quota readers (`planquota.go`, `tencent_usage.go`, `volcengine_usage.go`, `sub2api_usage.go`, `cline_usage.go`).
- No Decide (model-choosing endpoint) support (`decide.go`, `decide_group.go`, `decide_wire.go`, `ollama_decide.go`, `omlx_decide.go`, `mlxserve_decide.go`).
- No partner feed (`partners.go`, fetched list; hofund deliberately excludes it, see presets.toml header).
- No web search API fallbacks (Tavily, Brave, Exa, Firecrawl, You.com, SearXNG; `search_api.go`).
- `docs/feature-parity.md` row 2.7 names these 58 presets and links this file. Region rows live inside a preset; they are not a separate 94-entry catalog.

## Protocol-level quirks hofund must replicate

Per vendor (magpie `internal/gateway` unless noted):

- Anthropic betas: drop `anthropic-beta` values a provider refuses by name, Bedrock list (`betas.go`).
- Claude Code 2.1.x fields a relay may refuse: `thinking.display` values other than summarized/omitted (`anthropic_shapes.go`).
- DeepSeek: `\0` in tool schema patterns -> `\u0000` by byte patch, keeping key order for prompt caching (`deepseek_schema.go`); Responses custom tools other than apply_patch translated (`custom_tool.go`).
- Kimi/Moonshot: add `type` to enum/const schemas (`kimi_schema.go`); reasoning_content both ways.
- xAI: tool schema `pattern` rewritten for Rust regex (`grok_schema.go`); namespace rules (`grok_namespace.go`).
- Grammar-compiled routers (OpenRouter ModelRun via Cline): `oneOf` -> `anyOf` (`oneof_schema.go`).
- Gemini 3: keep and return `thought_signature` on function calls, including through the OpenAI-compatible API `extra_content.google.thought_signature` (`gemini_signature.go`, `gemini_sigstore.go`).
- Code Assist envelope `{model, project, request}` / `{response}` (`codeassist.go`).
- Bedrock Mantle: `/v1` vs `/openai/v1` prefix by model, retry the other on "isn't supported on this route" (`mantle.go`).
- Assistant prefill refused (OpenCode Go Claude, Volcengine Agent Plan, Vertex Gemini): end the conversation on a user message (`prefill.go`).
- Strict Chat validators refuse `strict: false`: retry without it (`strict_refused.go`).
- Undeclared tools in history (tool_search agents) for Anthropic: declare or convert (`undeclared_tools.go`).
- Max output lowered to the model or user limit (`maxoutput.go`); thinking turned back on for a model that refused "off" (`wire_effort.go`, `effort_update.go`).
- Native compaction pass-through (`native_compaction.go`), Codex compaction guard (`codex_compact_guard.go`).
- Zhipu/Z.ai 1113 retry at `/api/coding/paas/v4` (`internal/provider/zhipu_coding.go`).
